# testzone

This repository is intentionally scaffolded as a clean starting point for your project.

## Structure

- `src/` - application source code
- `tests/` - automated tests
- `docs/` - project documentation
- `.gitignore` - ignores common local artifacts

## Getting started

1. Add your project files under `src/`.
2. Add tests in `tests/`.
3. Document usage and notes in `docs/`.
4. Commit and push when ready.

## Notes

This repository is currently empty apart from the base structure, so you can begin adding code immediately.
